# 📊 Customer Behavior Dashboard
## 📌 Project Overview

The Customer Behavior Dashboard is an interactive Power BI report designed to analyze customer purchasing patterns across shopping malls.

This dashboard provides insights into:

💰 Total Revenue

📦 Total Quantity Sold

🏬 Revenue & Quantity by Shopping Mall

💳 Payment Method Distribution

📅 Revenue Trends Over Time

🛍 Category-wise Filtering

The goal of this project is to help businesses understand customer behavior and improve decision-making using data-driven insights.

🎯 Business Problem

Retail businesses need to:

Identify high-performing malls

Understand preferred payment methods

Track revenue trends

Analyze category-wise sales

Optimize marketing and inventory decisions

This dashboard helps answer those business questions effectively.
